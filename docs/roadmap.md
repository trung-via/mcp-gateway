# MCP Gateway roadmap

This is a proposed plan, not a claim that implementation has already occurred.

| Phase | Objective | Acceptance evidence | Status |
| --- | --- | --- | --- |
| P0 | Repository bootstrap, ADR, security baseline, work tree | Files present, reviewed | Draft bootstrap |
| P1 | Read-only MCP proof of concept | Tool discovery, JSON Schema, negative tests, CI | Not started |
| P2 | ChatGPT Chat interoperability | Authenticated tool invocation witnessed in real Chat | Not started |
| P3 | Windows and GitHub adapters | Project-scoped permissions, tests, audit receipts | Not started |
| P4 | Event/origin correlation and optional CDP bridge | Explicit exact-chat feasibility findings and tests | Not started |
| P5 | Reliability and release | Failure-mode tests, observability, release checklist | Not started |

No development lane is blocked on speculative chat wake-up support.
